## Report a security event or correct an advisory

The [DeepSweep advisories feed](https://deepsweep.ai/advisories) covers security events in the tools and runtimes developers use. Anyone can add to it:

- [Report a security event](https://github.com/deepsweep-ai/security-advisories/issues/new?template=report-security-event.yml) we have not covered.
- [Correct an advisory](https://github.com/deepsweep-ai/security-advisories/issues/new?template=correct-an-advisory.yml) that is wrong or out of date.

Each report is confirmed against two primary sources before it is published. [How reports are checked, how fast we reply and how credit works](https://deepsweep.ai/advisories/contribute).

## A flaw in a DeepSweep product

To report a security issue in a DeepSweep product privately, email [security@deepsweep.ai](mailto:security@deepsweep.ai). Please do not include credentials or personal data in a public issue.
